Keyboard Shortcuts

The full control reference for flight, the VAB, and map view.

Every table below lists the stock default keybind for a fresh KSP install. If a key on your machine doesn't do what's listed here, check Settings → Input in-game — every one of these is fully rebindable, and a handful of defaults have shifted slightly between KSP versions and localizations. Treat this page as "where to start looking," not gospel carved in stone.

Rebindable, and slightly version-dependent

All keybinds on this page live under Settings → Input (accessible from the main menu or the in-flight pause menu) and can be freely reassigned per action, including separate bindings for flight, EVA, and map view. A small number of defaults — mainly light toggles and some camera controls — have moved around across major KSP updates, so if a control listed here doesn't respond, open the Input settings and search for the action by name rather than assuming your keyboard is broken.

Physics warp vs. on-rails warp

The comma/period time warp keys behave differently depending on whether you're under thrust. Coasting with the engine off gives you fast, perfectly stable "on-rails" warp. Warping while a throttle is applied engages physics warp instead, which keeps the physics simulation running (and can worsen wobble on large or fragile craft) — see the Troubleshooting page for what goes wrong when this is pushed too far.

Translation & docking (RCS)

These only do anything once RCS is enabled (R) and the active craft has monopropellant and RCS thrusters. They're most relevant during rendezvous and docking — see the Rendezvous & Docking page for the full procedure.

KeyAction
H / NTranslate forward / backward
I / KTranslate up / down
J / LTranslate left / right
Caps LockToggle precision mode — makes RCS taps and rotation input much gentler, essential for the last few meters of a docking approach
Precision mode is easy to forget

Caps Lock is a toggle, not a hold — it's common to leave it on (or off) from a previous flight and wonder why your RCS taps feel wrong. Check the small indicator near the navball before your final approach.

Action groups

Action groups let you bind arbitrary part actions (deploy solar panels, toggle a light, decouple a specific stage, trigger science instruments) to a single keypress instead of hunting through right-click menus mid-flight.

KeyAction
1 – 9Trigger custom action groups 1 through 9
0Trigger the 10th custom action group
BackspaceTrigger the dedicated Abort group — conventionally wired to jettison/eject systems on crewed craft
  1. Select a part in the VAB/SPH and open its right-click context menu.
  2. Click the action group icon (or use the dedicated Action Groups tab in the editor's left toolbar) to see which actions that part offers — deploy, toggle, activate, and so on.
  3. Assign the action to a numbered group by clicking the group number, then repeat for any other parts that should fire together (for example, deploying every solar panel on the craft with one keypress).
  4. Test it on the pad before you rely on it in flight — a mis-assigned action group is much cheaper to catch on the launchpad than 20 minutes into a mission.

VAB / SPH building controls

Controls for the Vehicle Assembly Building and Spaceplane Hangar, where you design craft.

Key / actionEffect
Left-click + drag a partPick up and attach a part to the craft
Right-click a partOpen its context menu (info, fuel priority, actions)
RCycle radial symmetry (2x, 3x, 4x...)
Mouse scroll wheelZoom the camera in/out
Middle-mouse drag / arrow keysRotate the camera around the craft
W A S D Q E (while holding a part)Rotate the held part along its axes before placing it

The left-hand editor toolbar also has dedicated tool modes worth knowing by sight rather than by keybind: the Offset tool nudges a placed part's position freely, the Rotate tool spins a placed part without moving it, and the Root tool lets you re-designate which part the whole craft tree is built from. There's also an angle-snap toggle that locks rotation to fixed increments (handy for symmetric fins and RCS ports) versus fully freehand rotation.

Map view & maneuver nodes

Map view is where you plan orbits, set targets, and build maneuver nodes. See the Orbital Mechanics page for the full maneuver-node workflow.

Key / actionEffect

Drag a node's colored handlesAdjust that node's prograde/retrograde, normal/antinormal, or radial components
Right-click a nodeOpen the numeric node editor, or delete the node

Kerbal EVA controls

Once a Kerbal is outside the craft (EVA), a separate control scheme takes over for walking, running, and jetpacking around.

Key / actionEffect
Right-click a pod, then choose EVA (or use the crew portrait's EVA button)Send a Kerbal outside the craft
W A S DWalk / run forward, left, back, right
Hold Shift while movingSprint
SpaceJump, or fire the jetpack thruster in zero-g/low-g EVA
RToggle jetpack RCS-style translation mode when in open space
H / N / I / K / J / LJetpack translation (same layout as craft RCS) once the jetpack is active
Walk into a ladder or handrailGrab on automatically for climbing back aboard
Right-click while near the groundPlant a flag, or take a surface sample / EVA report, if the Kerbal is carrying the right equipment
The ones worth memorizing first
  • F5 / F9 — quicksave, quickload. Make this a reflex before every risky maneuver. It's the single biggest quality-of-life habit in the whole game; see Troubleshooting for why.
  • Caps Lock — precision/fine-control mode. Toggle it on for docking, precise landings, and any time your inputs feel too twitchy.
  • [ / ] — cycle control point. Essential the moment you're flying anything with more than one docking port or probe core.
  • Alt+click behaviors in the editor. In many editor contexts, holding Alt while clicking a part copies its current settings (like fuel priority or symmetry) onto the next part you place — a fast way to keep a craft's tanks configured consistently without re-editing each one by hand.
